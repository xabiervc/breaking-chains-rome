# Preimplementation Exit Criteria

## 100% documentary completion

The repository is document-complete only when design questions, campaign arc, chronology, narrative states, character relationships, canon, sensitive-content policy, accessibility requirements, platform matrix, performance targets, memory, save migration, privacy, localization, regression, load/error testing, and production gates are present and cross-referenced.

## Ready for vertical slice

- Core loop is playable in a greybox.
- Two resistance approaches work.
- Network variables visibly change.
- One non-protagonist can override Dama.
- Accessibility settings operate in the slice.
- CI, validators, and deterministic tests are green.
- No unresolved blocker in data contracts or canon.

## Ready for production

- Vertical-slice evidence meets scorecard thresholds.
- Main campaign content and research reviews are signed off.
- Target hardware meets measured budgets.
- Save migration and localization are tested.
- External playtest findings are triaged and closed or accepted.
- No critical/blocker defects and production rollback/support plans exist.

## Truth rule

Documentary completeness is not the same as implementation completion. The project must never claim 100% preimplementation or award readiness based only on prose.
