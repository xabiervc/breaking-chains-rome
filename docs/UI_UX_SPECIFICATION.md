# UI/UX Specification

## Principles

- Information is legible without requiring external documentation.
- Historical terminology is explained through optional codex entries.
- Language barriers are visible but never frustratingly opaque during required missions.
- Deterministic outcomes are communicated through clear state feedback.

## Required interfaces

- World map and route graph.
- Mission dependency map.
- Rescue ledger.
- Faction reputation.
- Language proficiency.
- Inventory and resource ledger.
- Evidence archive.
- Codex with fact/reconstruction/fiction distinctions.
- Accessibility menu.

## Save-state visibility

The player can inspect discovered routes, active lockdowns, faction states, supplies, rescued people, completed objectives, and permanent consequences.
