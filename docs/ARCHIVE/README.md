# Archive Policy

Legacy documents remain in place for traceability but are not implementation authority.

A document is archived when it is superseded, contains a `FINAL`, `PREMIUM`, `COMPLETE`, `100`, or phase-specific claim without a promotion record, or conflicts with the canonical set. Archived material may be mined for ideas but must not silently change runtime behavior.

Promotion requires a dated change record, affected stable IDs, reviewer, validation status, and explicit update to `docs/DOCUMENT_STATUS_INDEX.md`.
