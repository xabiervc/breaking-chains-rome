# Dialogue and Languages

## Voice policy

Characters speak historically researched in-universe languages. Repository dialogue drafts use English with metadata specifying intended voice language, register, translation mode, and subtitle behavior.

## Language matrix

| Region/context | Primary voices | Secondary voices |
|---|---|---|
| Rome and western Italy | Classical Latin | Greek, regional Italian varieties |
| Graecia and eastern commerce | Koine Greek | Latin, regional languages |
| Syria | Western Aramaic | Greek, Latin |
| Rural Egypt | Egyptian | Greek, Latin |
| North Africa | Punic, Latin | Greek |
| Hispania | Latin | Regional Iberian languages |
| Gaul | Latin | Celtic languages |
| Thrace | Thracian reconstruction | Greek, Latin |

## Dialogue metadata

Every scene must specify: scene ID, speakers, listener, date, location, emotional state, voice language, translation mode, subtitle language, knowledge constraints, and outcome.

## Translation modes

- Direct comprehension.
- Partial comprehension.
- Interpreter-mediated.
- Written translation.
- Gesture and object demonstration.

Never use invented ancient-language sentences without qualified review.
