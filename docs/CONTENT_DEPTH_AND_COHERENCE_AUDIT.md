# Content Depth and Coherence Audit

## Scope

This audit distinguishes a large document set from a coherent production plan. Every canonical document must answer what it changes, what consumes it, what proves it, and what remains uncertain.

## Required depth

- Gameplay variables have range, owner, mutation rule, feedback, save field, and test ID.
- Narrative states have entry, exit, visible consequence, recovery rule, and canon label.
- Characters have want, boundary, capability, relationship change, independent action, and authored outcome.
- Mission briefs have objective, pressure, approaches, fail-forward result, accessibility coverage, assets, audio, and regression ID.
- Historical claims have source, classification, confidence, affected content, and professional-review status.
- Technical targets are measured or explicitly marked as targets, never presented as achievements.

## Coherence checks

- No canonical document silently contradicts another.
- No variable exists only as prose.
- No scene exists without a gameplay or narrative function.
- No choice exists without visible feedback and a later consequence.
- No accessibility promise exists without a test case.
- No aspirational target is counted as completed evidence.

## Findings

The documentary package now has the required structure and traceability. Runtime depth remains an evidence question and is recorded separately in `docs/OPEN_EVIDENCE_REGISTER.md`.
