# Production Gates

## Gate 0 — documented preimplementation

Documentation, canon, data contracts, research classifications, source ledger, and review matrix complete.

## Gate 1 — validated foundation

Environment reproducibly installs; validators and tests pass; CI artifacts are archived.

## Gate 2 — vertical slice

One complete investigation-to-rescue-to-escape loop works with two approaches, consequences, accessibility controls, and authored audio/visual identity.

## Gate 3 — content lock

Main missions, dialogue, language metadata, historical classifications, art briefs, sound briefs, and accessibility test cases are locked.

## Gate 4 — release candidate

Target-hardware performance, save migration, crash stability, localization, accessibility, sensitivity, historical, art, audio, and regression gates pass.

## Gate 5 — ship readiness

No blocker/critical defects; rollback plan, support plan, known issues, credits, attribution, and build provenance are complete.

Aspirational award quality is a target for evidence-based craft, not a promise of award recognition.
