# Content Scope Matrix

## Mandatory for vertical slice

- One Ostia investigation and escape scenario.
- Dama, one affected person, one ally, one opposing authority, and one independent non-protagonist decision.
- Two viable approaches: quiet extraction and public disruption.
- Network variables: trust, supplies, exposure, reputation, organization, retaliation, information, cohesion.
- One shelter node, one route link, one cell, one evidence chain, one failure recovery.
- One compact environment with readable class/material contrast.
- Subtitles, speaker labels, remapping, visual audio cues, reduced effects, checkpoint retry.
- Placeholder-to-reviewed language metadata; no unreviewed ancient-language performance.

## Mandatory for production foundation

- Four-act campaign arc and chronology.
- All main mission stable IDs and state transitions.
- Research classification for historical claims.
- Save schema and migration baseline.
- Localization string IDs and fallback.
- CI validators, tests, deterministic replay, and error reporting.
- Accessibility test cases and compensated specialist playtests.

## Aspirational until validated

- Full ten-region content breadth.
- All optional activities and side missions.
- Console support.
- Final ancient-language voice performance.
- Final target-hardware performance budgets.
- Award-level polish and external recognition.

## Out of scope for first slice

- Complete empire-scale simulation.
- Procedural generation of historical speech.
- Player-controlled trafficking or abuse loops.
- Unbounded population simulation.
