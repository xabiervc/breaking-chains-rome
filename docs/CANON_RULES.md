# Canon Rules

## Authority order

1. Explicit current user decisions.
2. Canon records and stable-ID data.
3. GDD and approved design documents.
4. Research Bible and source ledger.
5. Drafts, prompts, generated suggestions, and legacy material.

## Conflict handling

A lower-authority document cannot silently override a higher-authority decision. Contradictions become an issue or change proposal with affected IDs and migration notes.

## Classification

Historical claims use FACT, RECONSTRUCTION, FICTION, or OPEN QUESTION. Fiction cannot be presented as archaeology or primary evidence.

## Change control

Every canon change records date, rationale, affected systems, migration impact, reviewer, and validation status. Stable IDs never change meaning silently.
