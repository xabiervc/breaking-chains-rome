# Known Limitations

- The repository is a design and preimplementation package, not yet a complete Unreal project.
- Exact Unreal minor version is not locked.
- Target hardware and frame-rate budgets are not locked.
- Ancient-language voice content requires specialists.
- Historical reconstruction requires expert review.
- Unreal binary assets are not present.
- Fire visuals and World Partition performance require profiling.
- Third-party C# support is intentionally not part of the canonical runtime.
- An LLM can generate source, data, tests, and setup instructions, but cannot truthfully claim visual quality, engine compilation, or playability without executing and verifying them.
