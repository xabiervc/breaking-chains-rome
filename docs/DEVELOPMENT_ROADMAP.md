# Development Roadmap

## Phase 0 — Canon lock

Freeze title, dates, protagonist, target network, regions, languages, final mission, and historical boundaries.

## Phase 1 — Narrative foundation

Complete story bible, character bible, faction matrix, timeline, and mission dependency graph.

## Phase 2 — World foundation

Complete region, city, route, interior, language, schedule, and economy specifications.

## Phase 3 — Content production

Write mission briefs, side missions, dialogue scene metadata, activities, codex entries, and rescue ledger data.

## Phase 4 — Systems prototype

Implement deterministic travel, schedules, reputation, stealth states, evidence, inventory, rescue logistics, and mission state persistence.

## Phase 5 — Vertical slice

Build Ashgrove Estate, Capua route, one escape mission, one side mission, one workshop, one safe house, and one language barrier.

## Phase 6 — Regional expansion

Add Rome, Ostia, Sicily, Alexandria, Antioch, Thrace, Hispania, and Gallia in dependency order.

## Phase 7 — Act III production

Implement the four target chains and evidence archive.

## Phase 8 — Rome finale

Implement evacuation, archive, fire simulation, final confrontation, escape, and epilogue.

## Phase 9 — Validation and historical review

Run automated continuity checks, playtest deterministic paths, conduct historical review, sensitivity review, localization review, and accessibility review.

## Phase 10 — Production lock

Freeze canonical data, lock voice scripts, record languages, finalize subtitles, and prepare release documentation.
