# Vertical Slice — Ashgrove to the Alban Hills

## Goal

Prove the core loop: observe, prepare, move, infiltrate, sabotage, escape, recover, and update the resistance network.

## Included

Ashgrove forge and south yard; transport wagon route; ACT-ROME-001 through ACT-ROME-007; SIDE-ITA-001; one workshop upgrade; one refuge; one patrol state; one forged-document interaction; one functional-Latin interaction with an administrative clerk; one permanent consequence: the Ashgrove register remains destroyed.

## Acceptance criteria

1. A new save completes the slice without undefined IDs.
2. Identical input produces identical patrol, objectives, rewards, and save state.
3. Estate hierarchy is understandable without a lore dump.
4. Fixed schedules can be observed and exploited.
5. Livia's forced loss is framed as a narrative event, not player incompetence.
6. The resource ledger records food, medicine, tools, and refuge capacity.
7. Reloading after ACT-ROME-007 preserves the destroyed register and fugitive status.

## Required test saves

`VS-NEW-001`, `VS-LEDGER-001`, `VS-AUCTION-001`, `VS-ESCAPE-001`, `VS-REFUGE-001`, `VS-FINALE-001`.
