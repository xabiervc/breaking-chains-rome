# Preproduction Freeze

## Baseline

The documentary Level-A baseline is frozen at the governance commit that introduces this file. Changes after this point must be implementation findings, approved canon changes, or evidence updates—not automatic expansion of the document set.

## Frozen decisions

- Core experience: resistance-network strategy adventure with investigation, negotiation, stealth, escape, and rebuilding.
- Core variables: trust, supplies, exposure, reputation, organization, retaliation, information, cohesion.
- Campaign frame: AD 54–64; Great Fire climax; no claim of abolition.
- First slice: `VS-OSTIA-001`, 20–35 minutes, quiet extraction versus public disruption.
- Historical policy: FACT, RECONSTRUCTION, FICTION, OPEN QUESTION.
- Primary platform: Windows PC; handheld secondary; console later.
- Ethical boundary: people are never inventory, commodities, or score multipliers.

## Change rule

A proposed change must state whether it affects identity, core loop, scope, canon, accessibility, technical contracts, or only presentation. Identity/core-loop/scope changes require owner approval and a new traceability review.
