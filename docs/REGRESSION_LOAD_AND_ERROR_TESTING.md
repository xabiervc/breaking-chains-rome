# Regression, Load, and Error Testing

## Regression

Run static validation, schema tests, unit tests, integration tests, deterministic replay, save migration, localization, accessibility persistence, and smoke playthrough on every release candidate.

## Load

Test maximum active cells/nodes, simultaneous route pressure, fire propagation events, crowd density, repeated evidence updates, and long-session memory growth.

## Recoverable errors

Errors must provide a safe fallback, actionable message, diagnostic ID, and recovery path. Missing optional content may degrade gracefully; missing required data must fail before destructive state changes.

## Exit criteria

No blocker or critical defect; no unexplained nondeterminism; no unrecoverable save corruption; no missing required localization key; no essential accessibility regression.
