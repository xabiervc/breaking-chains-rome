# Evidence and Investigation System

## Authority

`data/evidence-definitions.yaml` is the canonical registry. Mission documents provide authored acquisition context.

## Evidence states

`unknown -> located -> copied -> verified -> used -> archived`.

Evidence can additionally enter `compromised`, `destroyed`, or `published`. A destroyed original does not remove a verified copy.

## Target dossier requirements

Each Act III target requires exactly one operational record, one personal-link record, and one public-leverage record. A resolution mission cannot start without all three records verified.

## Optional evidence

`EVID-HIS-001` supports resource reductions and optional approaches but cannot replace any mandatory target dossier or Act IV gate.
