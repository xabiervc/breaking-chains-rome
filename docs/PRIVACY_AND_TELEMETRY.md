# Privacy and Telemetry

## Principles

Telemetry is opt-in where legally required, minimal, documented, and disabled by default for offline play. No content of private saves, voice recordings, raw text, or unnecessary identifiers is collected.

## Events

Collect only coarse technical events: crash category, build/platform, loading timing bucket, save failure category, accessibility feature usage in aggregate, and anonymized test cohort identifiers where consent exists.

## Controls

Explain purpose, retention, deletion/contact process, and offline behavior in plain language. Provide a settings toggle and do not gate gameplay on telemetry consent.

## QA

Verify no secrets or personal data enter logs, telemetry respects opt-out, and offline builds remain playable.
