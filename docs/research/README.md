# Research Bible

Research-backed design support for Breaking Chains: Rome. This package is not formal academic certification.

## Classification

- FACT: supported by primary evidence or broad specialist consensus.
- RECONSTRUCTION: plausible interpretation from incomplete evidence.
- FICTION: deliberately invented for the game.
- OPEN QUESTION: disputed or not recoverable with confidence.

## Confidence

- HIGH: supported by multiple specialist or institutional sources.
- MEDIUM: plausible but limited by context or interpretation.
- LOW: provisional creative hypothesis.

## Review status

- REQUIRED: specialist review before script or asset lock.
- RECOMMENDED: useful before production lock.
- NOT_REQUIRED_FOR_PREIMPLEMENTATION: documentation-level review is sufficient for now.

This research supports production decisions; it does not replace historians, archaeologists, linguists, sensitivity readers, accessibility specialists, or art/audio professionals.
