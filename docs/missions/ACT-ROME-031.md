# ACT-ROME-031 — The Mutiny at Philippopolis

- Act: III
- Target: Marcus Laelius Drusus (`CHAR-007`)
- Date: AD 63, winter
- Location: Philippopolis military road (`LOC-THR-001`)
- Type: Target resolution, mutiny, battlefield command
- Classification: FICTION

## Prerequisites

ACT-ROME-028, ACT-ROME-029, and ACT-ROME-030.

## Objectives

1. Position the veteran units.
2. Prevent the garrison reaching the civilian quarter.
3. Seize the payroll chest.
4. Broadcast Drusus's stolen-wage record.
5. Defeat Drusus's escort.
6. Capture Drusus alive.

## Fixed outcome

Drusus is captured; the garrison withdraws; unpaid veterans become allied; patrols become aggressive but predictable; `target.thrace.resolved=true`.
