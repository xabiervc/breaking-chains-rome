# ACT-ROME-036 — The City's Thirst

- Act: IV
- Date: AD 64, January
- Location: Rome, fountains, cisterns, aqueduct access points
- Type: Reconnaissance, logistics, infrastructure
- Classification: FICTION within historical framework

## Prerequisites

ACT-ROME-023, ACT-ROME-027, ACT-ROME-031, ACT-ROME-035.

## Objectives

1. Map the fixed water sources in the Subura, Aventine, Esquiline, and Tiber districts.
2. Identify three sources that remain reachable during a fire emergency.
3. Mark one safe crossing per district.
4. Deliver the map to Nicanor.
5. Return to Eirene's planning room.

## Fixed outcome

The water and street network becomes available to the final operation. Tier 1 evacuation is unlocked.

## Rewards

Map data; water-route upgrade; Act IV preparation state begins.
