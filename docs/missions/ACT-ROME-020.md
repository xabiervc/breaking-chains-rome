# ACT-ROME-020 — The Port Books

- Act: III
- Target: Aulus Secundus (`CHAR-005`)
- Date: AD 63, spring
- Location: Alexandria harbor archive (`LOC-AEG-001`)
- Type: Investigation, stealth, document copying
- Classification: FICTION

## Prerequisites

ACT-ROME-019 and an active Alexandria route.

## Objectives

1. Identify the archive clerk's fixed schedule.
2. Enter the port books room using the warehouse symbol.
3. Locate the operational shipping register.
4. Copy vessel, cargo, and ownership columns.
5. Verify the Varro seal with Livia's textile cipher.
6. Leave the original in place.

## Fixed outcome

`EVID-AEG-002` is verified as operational evidence. The player learns which warehouse contains captives and which contains records.

## Rewards

Read XP 400; Alexandria port archive discovered.
