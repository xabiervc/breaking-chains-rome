# ACT-ROME-021 — The Grain Diversion

- Act: III
- Target: Aulus Secundus (`CHAR-005`)
- Date: AD 63, summer
- Location: Nile grain depot (`LOC-AEG-001`)
- Type: Logistics, stealth, supply diversion
- Classification: FICTION

## Prerequisites

ACT-ROME-020.

## Objectives

1. Identify the grain allocation ledger.
2. Compare grain cargo with captive transport numbers.
3. Divert a fixed shipment to three safe kitchens.
4. Prevent a city-wide shortage.
5. Copy the allocation signature.
6. Return before the morning inspection.

## Fixed outcome

`EVID-AEG-003` is verified as personal-link evidence. Safe kitchens receive the fixed shipment and no famine is triggered.
