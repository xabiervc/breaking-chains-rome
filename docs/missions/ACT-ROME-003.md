# ACT-ROME-003 — Thread and Ash

- Act: I
- Date: AD 54, seven days before Livia's sale
- Locations: textile room, kitchen, burial wall
- Type: Preparation, social stealth, relationship
- Classification: FICTION

## Purpose

Establish Dama and Livia as strategic equals and introduce the textile cipher.

## Prerequisites

ACT-ROME-002.

## Ordered objectives

1. Find Livia in the textile room.
2. Retrieve red thread from the storehouse.
3. Collect willow bark from the kitchen medicine shelf.
4. Create the first three-symbol textile code.
5. Hide the code inside a folded work cloth.
6. Visit the burial wall after the evening bell.

## Success

Sets `relationship.livia.trust=2` and `knowledge.textile_cipher=1`; unlocks ACT-ROME-004. Red thread is in the third storehouse basket, willow bark is available during the evening kitchen shift, and the code means “Alexandria route,” not “Alexandria arrival.”

## Rewards

Read XP 100; one medicine unit; Livia trust +2.
