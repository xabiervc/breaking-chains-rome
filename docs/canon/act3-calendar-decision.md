# Canonical Act III Calendar Decision

## Decision

The four Act III target arcs are player-selectable after ACT-ROME-019. Their displayed dates are authored seasonal milestones, not a freely advancing global calendar. Selecting an arc does not make other arcs historically simultaneous; each arc resolves its regional operation at its assigned AD 63 seasonal milestone.

## Fixed milestones

- Alexandria: spring → summer → autumn → winter, ACT-ROME-020–023.
- Antioch: spring → summer → autumn → winter, ACT-ROME-024–027.
- Thrace: spring → summer → autumn → winter, ACT-ROME-028–031.
- Rome: spring → summer → autumn → winter, ACT-ROME-032–035.

The player may choose the first target arc, but missions within an arc remain ordered. The campaign clock commits the selected arc's seasonal milestone when its resolution mission succeeds. The other arcs remain available and use authored date presentation when selected.

This is an explicit gameplay abstraction, not a claim that all operations happened simultaneously in real history.
