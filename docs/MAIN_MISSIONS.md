# Main Missions

## Mission standard

Every mission receives a stable ID, fixed date range, prerequisites, locations, ordered objectives, failure states, success state, rewards, affected factions, reputation changes, historical classification, and deterministic tests.

## Dependency rule

Act II requires ACT-ROME-007. Act III requires ACT-ROME-019. The four Act III target chains may be completed in any order, but all four resolution missions are required for the complete canonical final operation. Act IV requires ACT-ROME-035 and all four Act III resolution missions.
